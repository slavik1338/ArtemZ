# Экспериментальная нейросеть для LIBS

Прототип определяет кандидатов элементов и сопоставляет наблюдаемые пики с
таблицей атомных линий. Используется многослойная нейросеть MLP, обучаемая на
синтетических смесях гауссовых линий. Это исследовательская исходная модель:
качество на реальных LIBS-спектрах без независимых размеченных образцов неизвестно.

## Установка и запуск

Python 3.12. Из каталога репозитория:

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python libs.py train --spectrum spectrum.csv --lines lines.csv --output model.joblib --tolerance-nm 0.1
.venv/bin/python libs.py analyze --spectrum spectrum.csv --model model.joblib --output result.json
```

В текущем окружении зависимости также могут быть уже доступны через `python`.
Модель сохраняется через joblib: загружайте только собственные доверенные файлы,
поскольку этот формат может исполнять код при загрузке.

## Входные данные

Спектр: CSV с заголовком `wavelength_nm,intensity`, длины волн в нм,
интенсивность в произвольных единицах. Нужны минимум 20 точек, уникальные длины
волн и конечные числа. Неравномерная сетка интерполируется на равномерную.
Все анализируемые спектры должны покрывать диапазон обучающего спектра.

Линии: CSV с заголовком
`element,ion,wavelength_nm,relative_strength`. `element` — символ элемента,
`ion` — стадия ионизации, `relative_strength` — положительный вес линии.
Подготовьте этот файл из выбранной выгрузки NIST ASD; прямое чтение произвольной
таблицы NIST пока не реализовано. Уберите пометки из числовых полей, выберите
наблюдаемые либо Ritz-длины волн и одну систему air/vacuum, совпадающую со спектром.
Не смешивайте Å и нм. Недостающие интенсивности нельзя молча заменять нулями.
Сохраните исходную выгрузку, параметры поиска и источник рядом с данными.
Официальная форма: https://physics.nist.gov/PhysRefData/ASD/lines_form.html

Параметр `--tolerance-nm` задаёт окно сопоставления, а также масштаб ширины
синтетических линий. Выбирайте его с учётом разрешения и погрешности калибровки
прибора. Это упрощение: ширину линии и точность шкалы следует отдельно оценить
перед применением к реальным данным. Слишком широкое окно смешивает линии.

## Результат и ограничения

JSON содержит оценки присутствия всех кандидатных элементов, наблюдаемые пики,
подходящие табличные линии, отклонения длин волн и признак неоднозначности.
Оценки нейросети не являются калиброванными вероятностями. Совпадение одной
линии не доказывает присутствие элемента. Относительные интенсивности NIST
не являются универсальными отношениями интенсивностей линий в LIBS-плазме.

Концентрация и её единица возвращаются как `null`. Количественный анализ
не реализован: для него необходимы стандарты с известными концентрациями
и сопоставимыми условиями измерений либо отдельная проверенная CF-LIBS-модель.
Нельзя нормировать оценки присутствия и выдавать их за массовые доли.
CF-LIBS требует проверки условий применимости, оценки температуры и электронной
плотности, учёта самопоглощения и ионизационного баланса; одних совпадений линий
и относительной интенсивности недостаточно.

Синтетическая проверка проверяет только заданный генератор, не точность анализа
реальных образцов. Тесты используют вымышленные линии, не выдаваемые за NIST.
Учебник Кремерса не использовался как проверенный источник: его текст в проект
не предоставлен. Для дальнейшей работы нужны реальные примеры спектров,
выгрузка NIST, разрешение прибора, система длин волн и условия регистрации.
